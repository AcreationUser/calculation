# Спектры — авторская панель

Мобильное статическое веб-приложение для учёта авторской статистики.

## Запуск
Откройте `index.html` в браузере или опубликуйте папку на GitHub Pages.

## Данные и резервные копии
Данные хранятся локально в браузере (`localStorage`). Используйте «Резервная копия» для экспорта JSON и «Импорт» для восстановления.

## Редактирование томов
Каждая карточка редактируется отдельно кнопкой «Ред.». Сохранение или отмена находятся внутри той же карточки. Общая статистика автоматически пересчитывается после сохранения. Фрагменты не входят в общий итог семи томов.

## Иконка
SVG-фавикон встроен непосредственно в `index.html` через data URI. Отдельный исходник находится в `icon.svg`.
