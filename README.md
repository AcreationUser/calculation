# Спектры — авторская панель v5

Мобильное статическое веб-приложение для учёта авторской статистики.

## Запуск
Откройте `index.html` в браузере или опубликуйте папку на GitHub Pages.

## Данные и резервные копии
Данные хранятся локально в браузере (`localStorage`). Используйте «Резервная копия» для экспорта JSON и «Импорт» для восстановления.

## Изменения v5
- Чуть уменьшен дополнительный верхний отступ; safe area Android сохранена.
- Месячные записи показываются от новых к старым в истории, архиве и диаграмме.
- Колонка сумм в списках месяцев выровнена по правому краю и имеет одинаковую ширину.
- Подсказка в истории изменена на «Новые сверху».

## Редактирование томов
Каждая карточка редактируется отдельно кнопкой «Ред.». Фрагменты не входят в общий итог семи томов.

## Иконка
SVG-фавикон встроен непосредственно в `index.html`. Отдельный исходник находится в `icon.svg`.
